#### Quantitative Trading

Since early 2026, I've been building and running an autonomous crypto trading research platform: an event-driven Python engine on PostgreSQL/TimescaleDB, fed by 12 exchanges and data sources. Every strategy change is backtest-gated before it goes to paper trading, and the system monitors itself with data-freshness checks, auto-restarts and alerting. (The code is private. Happy to walk through the architecture in a call).
